# richdem-rs (Python)

[![PyPI](https://img.shields.io/pypi/v/richdem-rs.svg)](https://pypi.org/project/richdem-rs/)
[![crates.io](https://img.shields.io/crates/v/richdem.svg)](https://crates.io/crates/richdem)
[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/opengeos/richdem-rs/blob/main/examples/richdem_rs_demo.ipynb)

Pure-Rust DEM hydrologic and terrain analysis for Python, ported from Richard Barnes's [RichDEM](https://github.com/r-barnes/richdem) and powered by [`terrio`](https://github.com/opengeos/terrio) for GDAL-free geospatial raster I/O.

See the [main repository](https://github.com/opengeos/richdem-rs) for full documentation, algorithm citations, and credits.
