# richdem-rs (Python)

Pure-Rust DEM hydrologic and terrain analysis for Python, ported from Richard Barnes's [RichDEM](https://github.com/r-barnes/richdem) and powered by [`terrio`](https://github.com/opengeos/terrio) for GDAL-free geospatial raster I/O.

See the [main repository](https://github.com/opengeos/richdem-rs) for full documentation, algorithm citations, and credits.
